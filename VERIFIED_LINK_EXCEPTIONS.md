# Manuellt verifierade länkundantag

Följande officiella kommunala sidor returnerar 404 till den automatiska
`curl`-kontrollen men är manuellt verifierade som aktuella och tillgängliga
via vanlig webbläsare och sökmotorindex.

- Gnosjö kommun:
  - https://www.gnosjo.se/uppleva-och-gora/foreningar-foreningsliv/bidrag-och-stod-for-foreningar
  - https://www.gnosjo.se/uppleva-och-gora/foreningar-foreningsliv/bidrag-och-stod-for-foreningar/grundbidrag
  - https://www.gnosjo.se/uppleva-och-gora/foreningar-foreningsliv/bidrag-och-stod-for-foreningar/bidrag-for-aktiviteter
  - https://www.gnosjo.se/uppleva-och-gora/foreningar-foreningsliv/bidrag-och-stod-for-foreningar/etableringsstod-startbidrag
- Hallstahammars kommun:
  - https://www.hallstahammar.se/uppleva-och-gora/foreningsliv/foreningsstod-och-bidrag
- Haparanda stad:
  - https://www.haparanda.se/fritid-och-kultur/foreningsliv/bidrag-och-stod-till-foreningar
- Markaryds kommun:
  - https://www.markaryd.se/sidor/uppleva-och-gora/foreningsinformation/foreningsbidrag.html
- Norbergs kommun:
  - https://norberg.se/kultur--fritid/forening/foreningsbidrag.html
- Övertorneå kommun:
  - https://overtornea.se/bygga-bo-miljo/trafik-och-vagar/

Dessa undantag ska omprövas vid framtida manuella länkrevisioner. De innebär
inte att automatiska 404-svar generellt ignoreras.
